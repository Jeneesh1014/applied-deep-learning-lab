# Applied Deep Learning Lab (SS26)

This repository contains my practical work and exercises for the **Applied Deep Learning** course (Summer Semester 2026) at Hof University of Applied Sciences.

## 📚 Course Overview

In this lab, I learn and implement the fundamentals of deep learning, including:

- Python programming basics
- Data handling using NumPy and Pandas
- Data preprocessing (splitting, normalization, standardization)
- Introduction to Neural Networks (classification & regression)
- Forward and backpropagation
- Hyperparameter tuning and optimization techniques
- Convolutional Neural Networks (CNNs)
- Basics of Deep Reinforcement Learning

## 🧪 Lab Work Structure

The repository is organized as follows:

- `notebooks/` → Jupyter notebooks for experiments, exercises, and practice
- `data/` → Datasets and data files (large datasets may be excluded from version control)
- `class_materials/` → Lecture notes, slides, and course resources
- `lab_materials/` → Hands-on lab notes and supporting materials
- `deep_dive/` → Additional in-depth topics, projects, and advanced content
- `venv/` → Local Python virtual environment (not typically committed to Git)
- `.gitignore` → Specifies files and folders ignored by Git
- `requirements.txt` → Python package dependencies
- `README.md` → Project overview, setup instructions, and repository documentation
- `notebooks/for_exam/` → Comprehensive exam-oriented notes, revision material, and high-probability practice questions designed to serve as the primary study resource for the course.
